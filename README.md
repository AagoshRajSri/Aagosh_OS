## 🌌 WHAT IS AAGOSHRAJ_OS?

Most developer portfolios are static grids of cards. **AagoshRaj_OS** is an immersive, fully interactive operating system running directly in your browser. 

Designed around the aesthetics of 90s cyber-terminals, anime HUDs, and mission-critical military command consoles, it delivers a tactile software experience complete with window management, live telemetry, sound design, reactive desktop companions, and an interactive command shell.

### 🌟 Core Highlights
- 🗔 **Dynamic Window Management**: Multi-tasking window manager with drag-and-drop, minimize, maximize, dynamic z-indexing, and taskbar docking.
- 💻 **Interactive Hacker CLI**: Built-in interactive terminal emulator with real command parsing, easter eggs, audio synthesizers, and dossier decryption.
- 📄 **Embedded Dossier Viewer**: Native PDF document reader for instant resume viewing and full-fidelity downloads.
- 📱 **Adaptive Matrix Layout**: Automatically morphs from a desktop multi-window OS on large screens to a sleek cybernetic dashboard on mobile devices.
- 🐈 **Autonomous Desktop Pets**: Interactive companions roaming the workspace that dynamically react to system load and open windows.
- 🔊 **Haptic Audio Subsystem**: Mechanical clicking, terminal keypress audio, window snap sounds, and ambient telemetry.

## ⚡ SYSTEM DEPLOYMENT / QUICKSTART

Want to deploy and run `AagoshRaj_OS` locally on your machine?

### 1. Clone the Repository
```bash
git clone https://github.com/AagoshRajSri/Aagosh_OS.git
cd Aagosh_OS
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Initialize Dev Environment
Run both the Vite frontend server and Express uplink server concurrently:
```bash
npm run dev
```

### 4. Access Local Interface
Open your browser to:
```text
http://localhost:5173
```
*Wait for the BIOS diagnostic bootloader to finish, click the screen to enable audio synthesizer, and enjoy exploring!*
