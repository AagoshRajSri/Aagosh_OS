# Aagosh_OS
**A tactile, interactive operating system masquerading as a portfolio.**

[![Live Preview](https://img.shields.io/badge/View_Live-000000?style=for-the-badge&logo=vercel&logoColor=white)](http://localhost:5173) 

</div>

<br/>

Most portfolios are static grids. **Aagosh_OS** is a fully functional web-based operating system designed to showcase distributed systems architecture, post-quantum cryptography integration, and GPU-accelerated interfaces.

It abandons the traditional scrolling webpage in favor of a windowed, multitasking environment.

<br/>

## ✦ Core Architecture

The system is built on an event-driven, high-performance foundation.

* **Dynamic Window Management:** A custom React-based z-index dispatcher allowing drag, snap, minimize, and focus states.
* **Command Line Interface:** A fully functional terminal emulator (`Terminal.exe`) capable of executing system directives and decrypting project files.
* **Haptic UI:** Integrated ambient audio, mechanical keystrokes, and physical UI feedback.
* **Hardware Acceleration:** GPU-composited UI elements using `Three.js` and `GSAP` to maintain a stable 60 FPS under load.

## ✦ Local Deployment

To run the environment locally:

```bash
git clone https://github.com/AagoshRajSri/Aagosh_OS.git
cd Aagosh_OS
npm install
npm run dev
```
Navigate to `http://localhost:5173`.
